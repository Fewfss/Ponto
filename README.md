# Ponto

Sistema de geração e gerenciamento de folhas de ponto — Fatec Zona Leste

O **Ponto** é uma plataforma web desenvolvida para automatizar o processo de geração de folhas de ponto de professores. O sistema substitui etapas manuais de preenchimento e organização por um fluxo estruturado, permitindo importar a grade horária do professor, armazenar seus dados e gerar a folha de ponto em formato `.docx`.

---

## Funcionalidades

**Professores**

* Cadastro e gerenciamento dos dados dos professores.
* Atualização dos dados cadastrais.
* Consulta das grades horárias importadas.
* Visualização dos componentes curriculares e aulas vinculadas.

**Folha de Ponto**

* Importação da grade horária do professor a partir de arquivos PDF.
* Extração automática dos dados do professor, componentes curriculares e horários.
* Armazenamento das informações importadas no banco de dados.
* Geração da folha de ponto em formato `.docx`.
* Seleção do mês e ano para geração da folha correspondente.
